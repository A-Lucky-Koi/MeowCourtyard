# 喵呜庭院 v2.1 更新说明

本次优化合成引导、手机布局和猫咪动作预览，保留现有30品种、480帧连续动作、永久解冻及每日奖励规则。无需重开游戏；使用同一浏览器和访问地址即可继续原来的v2存档。

## 更容易找到下一步

1. 进入合成小铺，棋盘上方可查看三份订单的目标与材料进度。
2. 点击想完成的订单，棋盘会标出相关物品，并提示还需要使用的菜篮子。
3. 点击“找合成”，查看可交付订单、可合并的一对物品或建议生成的系列。该按钮只给提示，不扣资源、不自动移动或合成。
4. 订单材料凑齐后，直接点棋盘上方的交付按钮，也可使用下方愿望清单中的“交付小礼物”。

“相邻连合”会保留已经凑齐订单所需的材料。每完成一次合并都会重新检查，因此连合过程中刚凑齐的订单也会受到保护。尚未凑齐的订单材料仍可能参与连合；手动拖动或点选合成保留玩家的选择。

体力和生成点增加恢复倒计时。生成点不足、棋盘无空位或步数耗尽时，菜篮子会禁用并显示原因；条件恢复后自动启用。

## 手机界面更集中

订单目标、棋盘与菜篮子之间的留白和控件尺寸已经调整。390×844手机首屏可同时查看目标、完整棋盘和五个菜篮子；详细愿望清单仍可向下滚动查看。320、360、390、650、768、850和1024像素宽度均通过合成页横向溢出检查。

## 逐帧查看猫咪动作

打开“猫咪图鉴”，进入任一猫咪档案：

- 点击“散步 · 8帧”或“吃饭 · 8帧”切换连续动作。
- 点击“暂停”停在当前帧；点击“下一帧”逐帧检查动作，再次播放可继续观看。
- 可选择0.5、1、1.5或2倍速度，界面同时显示当前帧和动作阶段。
- 进食动作包含准备、低头、啃咬、咀嚼、吞咽与抬头，可放慢观察。

预览操作不会扣金币或改变猫咪养成进度。图集未加载完成时显示静态姿态，加载后切换连续动作；同一品种复用已加载图集。猫咪离开可见区域、页面进入后台或系统开启“减少动态效果”时暂停自动播放。减少动态效果模式下仍可手动查看下一帧。

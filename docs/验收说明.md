## 已知范围

- 本地单机实现，未验证云服务、支付、广告、账号或服务端反作弊，因为本包不包含这些服务。
- 每种猫咪有8帧走路与8帧进食，使用独立逐帧画面；睡觉、呼噜、晒太阳使用原姿态与轻动效。v2.1改善播放与预览，未增加图片数量，也未实现骨骼动画。
- 无外部字体、图片或音效下载；源码和所有运行资源都在包内。
- 原始生成图集供后续编辑参考；实际运行使用新版4×4动画图集以及原版独立PNG。

## 复测

在项目目录执行 `npm test`；没有npm但有Node时使用：

```bash
node --test tests/engine.test.cjs tests/engine-v2.test.cjs tests/assets.test.cjs tests/animations.test.cjs tests/guidance.test.cjs
```

构建静态发布目录使用 `npm run build`，或 `node tools/build.cjs`。

启动游戏后，在设置中进入素材试玩，检查30只猫咪和4地图；退出模式应恢复正式进度。该模式不会把测试资源写入正式存档。

在合成小铺点击订单目标与“找合成”，观察高亮及资源是否保持不变；凑齐订单后使用顶部交付。打开任一猫咪档案，切换“吃饭”，暂停并连续点击“下一帧”，应能逐帧查看低头、啃咬、咀嚼、吞咽等阶段。

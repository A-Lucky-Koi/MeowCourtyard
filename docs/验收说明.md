# 验收说明

## 已完成的验证

- 21项规则和资源测试：30品种、5条升级链、210张独立透明PNG、30套动作条、地图与音效文件、二合一、相邻合成边界、体力/生成点恢复、满棋盘、订单计数、重复结算、领养容量、领养位置、地图解锁、离线收益上限、存档校验、前9关模拟。
- Edge/Chromium实际浏览器交互：点击进入庭院、抚摸猫咪、四种庭院动作、指针拖拽、生成与订单交付、通关结算、切换界面后续玩、刷新恢复、图鉴搜索筛选、领养、四地图试玩、退出试玩恢复正式进度、存档文件导出/导入。
- 1440×1000桌面和390×844手机布局；手机触屏双点合成；检查无横向页面溢出。
- 直接使用file协议打开index.html、开始关卡并生成64格棋盘。
- 浏览器流程中无JavaScript异常、无资源404；图片加载检查通过。
- 静态构建脚本运行成功。测试环境提供Node，没有全局npm，所以使用等价的 `node --test tests/engine.test.cjs tests/assets.test.cjs` 和 `node tools/build.cjs` 执行验证。

浏览器步骤记录见 `browser-test-results.json`，实际截图见 `previews`。

## 已知范围

- 本地单机实现，未验证云服务、支付、广告、账号或服务端反作弊，因为本包不包含这些服务。
- 猫咪是每品种6姿态图与程序微动画，行走2帧。不是高帧率逐帧角色动画。
- 无外部字体、图片或音效下载；源码和所有运行资源都在包内。
- 原始生成图集供后续编辑参考；实际运行采用已整理的独立PNG。

## 复测

在项目目录执行 `npm test`；没有npm但有Node时使用 `node --test tests/engine.test.cjs tests/assets.test.cjs`。

启动游戏后，在设置中进入素材试玩，检查30只猫咪和4地图；退出模式应恢复正式进度。该模式不会把测试资源写入正式存档。

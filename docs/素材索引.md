## 场景与界面

`assets/scenes/entrance.png` 为进入插画；garden / greenhouse / lake / rooftop 为四张独立地图，均1536×1024。界面控件由HTML/CSS绘制，可以直接交互，实际截图位于 `docs/previews`。

## 音效

`purr.wav`（3.2秒）、`merge.wav`（0.45秒）、`reward.wav`（1.1秒），22050Hz、16-bit、单声道。通过 `node tools/generate-audio.cjs` 可重新生成。

## 源图与边界

原始6组猫咪图集、1组物品图集及卷毛猫呼噜修正版保留在 `assets/atlases`。运行时走路和进食使用新版4×4连续图集，其他姿态使用独立切图。新增篮子在 `assets/ui/generator-basket.png`，新增提示词见 `v2生成提示词.json`。AI生成品种是风格化美术表达，不是品种标准鉴定图。每张素材的路径、尺寸、源图位置见 `assets/manifest.json`。

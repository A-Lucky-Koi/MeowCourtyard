# 《喵呜庭院》猫咪合成消消乐 · 游戏设计方案

版本:v1.0 | 日期:2026-09-25
类型:二合一合成(Merge-2)+ 庭院放置养猫 | 参考产品:浪漫餐厅、Merge Mansion

---

## 1. 产品定位

- **核心体验**:合成棋盘解压(主玩法)+ 云养猫陪伴(副玩法),双循环互相供血
- **目标用户**:18–40 岁休闲玩家,女性向为主
- **一句话卖点**:"合成闯关养猫,猫咪替你打工攒钱建庭院"

---

## 2. 核心循环

```
进入关卡(扣体力) → 合成物品、完成猫咪订单 → 获得金币/星星/体力
      ↑                                                    ↓
回关卡 ← 猫咪互动产出小奖励 ← 庭院放猫、扩建 ← 金币买道具/买猫 ← 星星解锁庭院区域
```

- **大循环**:闯关 → 资源 → 庭院养成 → 解锁新地图 → 养更多猫
- **小循环**(关卡内):生成物品 → 二合一升级 → 凑订单 → 交付 → 新订单

---

## 3. 关卡玩法(合成棋盘)

### 3.1 棋盘规则
| 项 | 设计 |
|---|---|
| 棋盘 | 8×8 = 64 格,关卡可裁剪为 6×6(新手)~ 10×10(后期) |
| 生成器 | 每关 2~3 个,点击消耗"生成点"产出 L1 物品 |
| 生成点 | 每关初始 40,每 10 秒 +1,上限 60;可用道具补充 |
| 合成 | 同链同级两两拖合 → L+1;≥3 个同级连成一片可一键链式合成 |
| 订单 | 猫咪气泡下单(如 1×L4 烤鱼 + 2×L3 毛线球),点击交付 |
| 目标 | 时限/步数内完成全部订单;剩余资源折算金币与 1~3 星评价 |

### 3.2 合成链示例
| 链 | L1 | L2 | L3 | L4 | L5 | L6 |
|---|---|---|---|---|---|---|
| 食物链(猫碗生成) | 小鱼 | 鱼干 | 鲜鱼 | 烤鱼 | 猫饭 | 豪华猫宴 |
| 玩具链(毛线篮生成) | 线头 | 毛线球 | 逗猫棒 | 猫爬架 | 猫城堡 | 梦幻乐园 |
| 植物链(种子袋生成) | 种子 | 幼苗 | 盆栽 | 花束 | 花坛 | 猫薄荷园 |

### 3.3 手感保底机制
- 生成器权重动态调整:订单所需链的生成权重 ×1.5(缺什么来什么)
- 棋盘满且无可合成:提示用"刷新"道具,否则失败结算(失败不重复扣体力)

## 4. 体力系统

| 项 | 数值/规则 |
|---|---|
| 体力上限 | 30(可用钻石永久扩容,每级 +5,上限 60) |

| 广告获取 | 激励视频 +5 点,每日上限 3 次 |
| 钻石购买 | 30 钻 = 补满体力 |

## 5. 经济系统

### 5.1 四种资源

## 7. 庭院系统

### 7.1 地图与解锁
- 4 张庭院地图:新手庭院(默认)→ 阳光花房 → 湖畔木屋 → 星空天台
- 解锁条件:玩家等级 + 金币门槛(见 5.2);每张图独立布置、独立容量
- 庭院网格:初始 6×6,可扩建至 10×10(影响装饰与可放猫数)

### 7.2 猫咪
- **获取**:关卡掉落"猫爪徽章"集章兑换、商店直购、活动/扭蛋
- **属性**:species_id、稀有度(N/R/SR/SSR)、亲密度(0~100)、饥饿度(0~100)、性格(文静/活泼/贪睡,影响行为权重)
- **容量规则**:庭院猫数 ≤ 容量;购买超出时弹窗引导"放入收藏室"或"扩容"

### 7.3 收藏室
- 不限量陈列墙(分页加载),支持图鉴查看、"召唤到庭院"(满员时提示扩容)

### 7.4 猫咪行为 AI(状态机)
状态集合:待机 Idle / 走动 Walk / 睡觉 Sleep / 吃饭 Eat / 晒太阳 Sunbathe / 玩耍 Play / 互动 Interact(玩家点击触发)

| 状态 | 持续时间 | 进入条件/权重 |
|---|---|---|
| 待机 | 20~40s | 默认状态 |
| 走动 | 直至到达目标点 | 待机到期后大概率转移 |
| 睡觉 | 60~180s | 夜间权重 0.5,贪睡性格 ×1.5 |
| 吃饭 | 30s | 饥饿度 >50 时权重 ×3,需背包有猫粮 |
| 晒太阳 | 45~120s | 白天(6–18 点)权重 0.35,SSR 猫概率展示特写 |
| 玩耍 | 30~90s | 活泼性格权重提升;可玩庭院装饰(毛线球道具) |
| 互动 | 10~15s | 玩家点击猫咪触发,亲密度 +2 |

- **行为产出**:晒太阳每 10s 亲密度 +1(每日上限 +30);互动概率掉小礼物(金币/体力,每日上限 3 次)
- **权重表按时段与性格动态计算**,每 10 分钟由服务端/客户端各刷新一次种子

### 7.5 离线模拟(Fast-Forward)
- 存档只存:当前状态 + 状态到期时间戳 + 属性快照
- 上线时按经过时间快进模拟(上限 4 小时),按权重表推进状态机,重新随机当前状态
- 亲密度/礼物结算由服务端按上限校验,防止刷取

## 8. 程序执行细节

### 8.1 技术栈
| 层 | 选型 |
|---|---|
| 客户端 | Cocos Creator 3.x + TypeScript(包体小、热更友好) |
| 服务端 | Java Spring Boot(业务)+ Netty(网关),或 Node.js 全栈 |
| 存储 | MySQL(存档)+ Redis(会话/排行榜/限流)+ 对象存储(配置/资源) |
| 数据管道 | 埋点 → Kafka → Flink/离线任务 → ClickHouse(分析库) |

### 8.2 模块划分
Account(账号)/ Level(棋盘、订单、合成)/ Economy(货币、体力)/ Courtyard(地图、猫咪、AI)/ Item / Social(好友赠送)/ Analytics(埋点上报)

### 8.3 关键算法
1. **棋盘模型**:一维数组 64 格,每格 {chain_id, level, generator_flag};合成检测用 DFS 找同类同级连通块,≥2 触发合成,支持链式
2. **生成器权重**:基础权重 × 订单需求系数(1.5)± 连败补偿(+0.1/次,连胜衰减)
3. **关卡种子**:服务端下发随机种子,客户端确定性回放;断线重连按种子 + 操作序列恢复
4. **离线体力**:energy_next_ts 时间戳,登录时 `min(上限, 存量 + floor((now-ts)/300s))`

### 8.4 网络与弱网
- 强校验操作(扣体力、货币变更、购买)必须走服务端,客户端只发"意图"
- 棋盘内拖动可客户端预演,结算时服务端按种子回放校验,防改包
- 弱网:本地乐观队列 + 重传;版本号(version)防旧包覆盖新存档

### 8.5 反作弊
- 货币/体力变更走服务端事务,全量货币流水(user_currency_log)
- 关键请求带时间戳 + HMAC 签名;异常频率(如 10 秒内 50 次合成)熔断封禁

## 10. 数据分析体系

### 10.1 埋点事件(详见 analytics_events.sql)
| 事件 | 触发时机 | 关键参数 |
|---|---|---|
| register / login | 注册/登录 | channel, version |
| level_enter | 进关卡 | level_id, energy_cost, remain_energy |
| order_complete | 订单交付 | level_id, chain_id, item_level, gold, star |
| level_end | 关卡结束 | result, stars, score, duration, orders_done, booster_used, revive_used |
| currency_change | 货币变动 | currency_type, delta, reason, balance |
| energy_change | 体力变动 | delta, reason(自然恢复/购买/赠送) |
| item_use / shop_buy | 用道具/购买 | item_id, goods_id, price_type, price |
| cat_obtain / cat_place / cat_to_collection | 获得猫/放置/入收藏室 | species_id, rarity, courtyard_id |
| cat_behavior | 猫咪行为 | cat_uid, behavior, duration, scene(庭院ID) |
| ad_show / ad_complete / iap_purchase | 商业化 | placement_id, product_id, price |

### 10.2 指标字典
| 模块 | 指标 | 口径 |
|---|---|---|
| 活跃 | DAU / MAU / 粘性 | 当日/当月去重登录 |
| 留存 | D1 / D7 / D30 | 新增用户 N 日后回访比例 |
| 关卡 | 进入→完成转化、失败卡点 TopN、三星率 | level_end 漏斗 |
| 合成 | 人均订单数、链式合成率、平均链深度 | order_complete 聚合 |
| 体力经济 | 日均消耗/获取比、溢出率、自然恢复占比 | energy_change |
| 庭院 | 养猫渗透率、人均猫数、行为触发率、收藏室使用率 | cat_* 事件 |
| 商业化 | 广告渗透率、eCPM、付费率、ARPU/ARPPU、LTV | ad_/iap_ 事件 |

### 10.3 看板页面(4 页)
1. **实时总览**:在线人数、DAU、收入、广告展示(分钟级刷新)
2. **新用户留存**:D1/D7/D30 曲线、分渠道留存、新手漏斗(注册→首关→次日)
3. **关卡与合成**:关卡通过率热力图、失败卡点榜、订单难度分布
4. **商业化与养成**:收入构成、体力经济健康度、养猫渗透与付费交叉分析

### 10.4 分析库示例 SQL
```sql
-- 昨日 D1 留存
SELECT COUNT(DISTINCT IF(DATEDIFF(event_date, register_date)=1, user_id, NULL))
     / COUNT(DISTINCT user_id) AS d1_retention
FROM dwd_user_day WHERE register_date = CURDATE() - INTERVAL 1 DAY;

-- 关卡漏斗
SELECT level_id,
       COUNT(*)                                                AS enters,
       SUM(result='win')                                       AS wins,
       SUM(booster_used>0)                                     AS booster_used,
       SUM(revive_used=1)                                      AS revived
FROM dwd_level_end
WHERE event_date = CURDATE()
GROUP BY level_id ORDER BY level_id;
```

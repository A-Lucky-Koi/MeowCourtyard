# v2.0 更新说明

## 菜篮子与冰格

五类基础物品各有对应菜篮子。点击后，篮子弹跳，物品沿抛物线飞入第一个未冻结的空格；扣点和落子在动画开始前一次性完成，连续点击、导航和刷新不会重复生成或丢物品。满棋盘和点数不足时不扣费。

新庭院共12个初始冰格，位于右侧两列。合成后的目标格上下左右若有冰格，就永久解冻。移动、不同物品合成失败、满级物品、升级卡和交付不会误解冻。自动相邻合成遵守相同规则。整理棋盘只打乱未冻结位置。

解冻进度保存于存档的 `frozenCells`（仍冻结的格号）。清空数组代表永久完成；后续关卡不会重置。结束本关只清空棋盘和未完成订单，不影响解冻记录。

## 两项每日奖励

每个游戏页面顶部均提供“每日登录体力”和“购物金币礼金”入口。体力最多到账10点，上限30；满体力时领取机会保留，未满但空间不足10时只到账剩余容量。购物金币每次300。两项独立、各每天一次，北京时间00:00刷新，已领按钮显示状态。

日期回拨至已领取日期之前也不会重复发放。本项目为本地单机，存档可自行编辑，没有服务端防作弊。

## 30种猫咪连续动作

每个品种新增一张4列4行透明图集，每格256×256：前8帧走路，后8帧吃饭，共480帧。素材位于 `assets/cat-animations/`，相邻JSON记录帧坐标、动作名称、阶段和停留时间。

走路每帧115ms，完整步态920ms。吃饭8帧分别停留240、220、240、170、170、180、300、260ms，表现准备、低头、啃咬、咀嚼、吞咽、抬头。庭院与猫咪档案共用同一播放器。行走方向随目标位置调整；喂食或抚摸时停在当前可见位置。

睡觉、呼噜、晒太阳保留原有姿态与动效。播放器在标签页隐藏时暂停更新；系统开启减少动态效果时显示静态帧。

## 旧存档与运行

版本号升级为2，继续使用 `meow-courtyard-v1` 存储键，确保同地址打开项目时自动找到旧进度。v1数据会迁移为v2，资源和棋盘不变，冰格视为全部解锁。当天已领取旧礼包时两项新奖励同步标记已领。

在Trae打开项目根目录，执行 `npm run dev`。无需安装npm依赖，也能直接打开 `index.html`。更新前可从设置导出存档；更新后仍需使用相同浏览器和端口。
